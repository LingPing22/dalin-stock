# Dalin Stock — ລະບົບຫຼັງບ້ານ ແລະ ສະຕັອກລັອດ (Offline-First)

ແອັບສຳລັບແມ່ຄ້າທີ່ຂາຍສິນຄ້າແບບ **ຊັ່ງກິໂລ** ຫຼື **ແບ່ງຂາຍເປັນລັອດ** (ສິນຄ້າສະປ່າ, ຂອງສົດ, ຊີ້ນ, ໝາກໄມ້ …).
ເຮັດວຽກ **ບໍ່ຕ້ອງມີເນັດ**, **ບໍ່ມີ Server / Database ພາຍນອກ** — ຂໍ້ມູນທັງໝົດເກັບໃນ iPad / ມືຖືຂອງຜູ້ໃຊ້ 100%.
ເອົາຂຶ້ນ **GitHub Pages** ໄດ້ຟຣີ ບໍ່ຕ້ອງເຊົ່າ Domain ຫຼື ຕັ້ງ DNS.

## 1. ລະບົບເຮັດຫຍັງໄດ້ແດ່

| **ລັອດສິນຄ້າ** | ຮັບຂອງເຂົ້າ: ວັນທີ, ຊື່, ໜ່ວຍ (ກິໂລ / ກ້ອນ / ຖົງ / ແພັກ / ມັດ / ອັນ), ຈຳນວນ, ຕົ້ນທຶນລວມ, ລາຄາຂາຍ → ຄິດ **ຕົ້ນທຶນສະເລ່ຍ/ໜ່ວຍ**, ກຳໄລ/ໜ່ວຍ, ຈຸດຄືນທຶນ ໃຫ້ທັນທີ • ປຸ່ມ "ບວກ 30% / 50% …" ຕັ້ງລາຄາໄວ • ປິດລັອດ (ບັນທຶກສ່ວນທີ່ເຫຼືອເປັນນ້ຳໜັກຫາຍໄດ້) |
| **ຄ່າໃຊ້ຈ່າຍ** | ຄ່າຖົງ, ຄ່າເດີນທາງ, ນ້ຳກ້ອນ, ຄ່າບ່ອນຂາຍ … • ຜູກກັບລັອດໄດ້ (ເຊັ່ນ ຄ່າຂົນສົ່ງລັອດນີ້ → ນັບເຂົ້າທຶນທີ່ຕ້ອງເອົາຄືນ) |

## 2. ສູດຄິດໄລ່ (ຢູ່ໃນ `src/lib/calc.js`)

```
ຕົ້ນທຶນສະເລ່ຍ/ໜ່ວຍ   = ຕົ້ນທຶນລວມ ÷ ຈຳນວນທີ່ຮັບມາ
ເຫຼືອ               = ຮັບມາ − ຂາຍແລ້ວ − ຂອງເສຍ/ແຖມ/ຫາຍ

ທຶນທີ່ຕ້ອງເອົາຄືນ     = ຕົ້ນທຶນລວມ + ຄ່າໃຊ້ຈ່າຍທີ່ຜູກກັບລັອດ
ຄືນທຶນແລ້ວ ເມື່ອ      ເງິນຂາຍໄດ້ຂອງລັອດ ≥ ທຶນທີ່ຕ້ອງເອົາຄືນ
ຍັງຂາດ              = ທຶນທີ່ຕ້ອງເອົາຄືນ − ເງິນຂາຍໄດ້
ຕ້ອງຂາຍອີກ          = ຍັງຂາດ ÷ ລາຄາຂາຍ  (ປັດຂຶ້ນ)

ຄາດການ (ຖ້າຂາຍໝົດ):
  ເງິນລວມ           = ເງິນຂາຍໄດ້ແລ້ວ + ເຫຼືອ × ລາຄາຂາຍ
  ກຳໄລສຸດທິ         = ເງິນລວມ − ທຶນທີ່ຕ້ອງເອົາຄືນ

ສະຫຼຸບລາຍວັນ:
  ກຳໄລສຸດທິ = ເງິນສົດຮັບຈິງ
            − ຕົ້ນທຶນຂອງທີ່ຂາຍໄປ   (ຈຳນວນ × ຕົ້ນທຶນສະເລ່ຍ)
            − ຂອງເສຍ/ແຖມ/ຫາຍ     (ຈຳນວນ × ຕົ້ນທຶນສະເລ່ຍ)
            − ຄ່າໃຊ້ຈ່າຍຍ່ອຍຂອງມື້ນັ້ນ
```

ທົດສອບສູດທັງໝົດດ້ວຍ `npm test` (12 ກໍລະນີ ລວມທັງການຂາຍເກີນ ແລະ ເລກທົດສະນິຍົມ).

## 4. ເອົາຂຶ້ນ GitHub Pages (ບໍ່ໃຫ້ຂຶ້ນ Not Found)

> ⚠️ **Repo ຕ້ອງເປັນ Public** ຖ້າໃຊ້ບັນຊີ GitHub ຟຣີ — GitHub Pages ຂອງ repo ແບບ Private ຕ້ອງໃຊ້ແຜນເສຍເງິນ.
> ໂຄດເປັນ Public ບໍ່ເປັນຫຍັງ ເພາະຂໍ້ມູນການຂາຍຢູ່ໃນເຄື່ອງຂອງແຕ່ລະຄົນ ບໍ່ໄດ້ຢູ່ໃນ repo.

### ທາງເລືອກ A — ອັດຕະໂນມັດດ້ວຍ GitHub Actions (ແນະນຳ)

1. ສ້າງ repo ໃໝ່ເທິງ GitHub (ເຊັ່ນ `dalin-stock`), ຕັ້ງເປັນ **Public**.
2. ອັບໂຫຼດໂຄດທັງໝົດຂອງໂຟນເດີນີ້ (ລວມທັງໂຟນເດີ `.github`) — ໃຊ້ GitHub Desktop ຫຼື:
   ```bash
   git init
   git add .
   git commit -m "Dalin Stock"
   git branch -M main
   git remote add origin https://github.com/<ຊື່ບັນຊີ>/dalin-stock.git
   git push -u origin main
   ```
3. ໄປທີ່ repo → **Settings → Pages → Build and deployment → Source** → ເລືອກ **GitHub Actions**.
4. ໄປແຖບ **Actions** → ລໍຖ້າ "Deploy to GitHub Pages" ເປັນສີຂຽວ (1–2 ນາທີ). ຖ້າມັນແລ່ນກ່ອນຂັ້ນຕອນ 3 ແລ້ວລົ້ມ ໃຫ້ກົດ **Re-run jobs**.
5. ລິ້ງຂອງແອັບ: **`https://<ຊື່ບັນຊີ>.github.io/dalin-stock/`**

ທຸກຄັ້ງທີ່ push ເຂົ້າ `main` ເວັບຈະອັບເດດເອງ.

### ທາງເລືອກ B — ບໍ່ຕ້ອງໃຊ້ Node / Actions (ອັບໂຫຼດໄຟລ໌ສຳເລັດຮູບ)

1. ແຕກໄຟລ໌ `dalin-stock.zip` → ເປີດໂຟນເດີ `2-ready-to-upload` (ໄຟລ໌ທີ່ build ແລ້ວ).
2. ສ້າງ repo Public ໃໝ່ → **Add file → Upload files** → ລາກ **ທຸກໄຟລ໌ທີ່ຢູ່ຂ້າງໃນ** (index.html, assets/, sw.js … ບໍ່ແມ່ນລາກໂຟນເດີນອກ) → Commit.
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`** → Save.
4. ລໍຖ້າ 1–2 ນາທີ ແລ້ວເປີດ `https://<ຊື່ບັນຊີ>.github.io/<ຊື່-repo>/`

### ເປັນຫຍັງແອັບນີ້ຈຶ່ງບໍ່ຂຶ້ນ Not Found

ຕັ້ງຄ່າໄວ້ໃນ `vite.config.js` ແລ້ວ:

```js
export default defineConfig({
  base: './',   // ທີ່ຢູ່ໄຟລ໌ແບບສົມທຽບ → ໃຊ້ໄດ້ກັບ repo ຊື່ຫຍັງກໍ່ໄດ້
  ...
})
```

| ອາການ | ສາເຫດ | ແອັບນີ້ແກ້ແລ້ວແນວໃດ |
|---|---|---|
| ໜ້າຂາວ, ໄຟລ໌ `.js` / `.css` ຂຶ້ນ 404 | `base` ຜິດ (ຄ່າເລີ່ມຕົ້ນ `'/'` ຈະໄປຫາໄຟລ໌ທີ່ `github.io/assets/…` ແທນ `github.io/<repo>/assets/…`) | `base: './'` — ຫຼື ຖ້າຢາກລະບຸຕາຍຕົວ ໃຫ້ໃຊ້ `base: '/<ຊື່-repo>/'` (ສະກົດໃຫ້ຖືກ, ໂຕໃຫຍ່-ນ້ອຍມີຜົນ) |
| ເປີດໜ້າຫຼັກໄດ້ ແຕ່ Refresh ໜ້າອື່ນແລ້ວ 404 | ໃຊ້ `BrowserRouter` (`/sell`) ເຊິ່ງ GitHub Pages ບໍ່ຮູ້ຈັກ | ໃຊ້ລິ້ງແບບ hash: `…/dalin-stock/#/sell` |
| ໄຟລ໌ທີ່ຂຶ້ນຕົ້ນດ້ວຍ `_` ຫາຍ | Jekyll ຂອງ GitHub ຂ້າມໄຟລ໌ເຫຼົ່ານັ້ນ (ທາງເລືອກ B) | ມີໄຟລ໌ `.nojekyll` ໃນ `public/` ແລ້ວ |
| ທັງເວັບ 404 | Pages ຍັງບໍ່ເປີດ / Source ຜິດ / repo ເປັນ Private / ຫາກໍ່ deploy | ກວດ Settings → Pages; ລໍຖ້າ 1–2 ນາທີ |
| ອັບເດດແລ້ວແຕ່ຍັງເຫັນເວີຊັນເກົ່າ | ແອັບເກັບໄຟລ໌ໄວ້ໃຊ້ອອບລາຍ | ແອັບຈະສະແດງແຖບ "ມີເວີຊັນໃໝ່ — ອັບເດດດຽວນີ້" |

## 5. ຕິດຕັ້ງໃສ່ iPad / iPhone

1. ເປີດລິ້ງ GitHub Pages ດ້ວຍ **Safari**
2. ແຕະ **ແບ່ງປັນ (Share)** → **Add to Home Screen / ເພີ່ມໃສ່ໜ້າຈໍໂຮມ** → Add
3. ເປີດແອັບຈາກໄອຄອນ — ເປີດເຕັມຈໍ ແລະ ໃຊ້ໄດ້ຕອນບໍ່ມີເນັດ (ຕ້ອງເປີດຕອນມີເນັດ 1 ເທື່ອກ່ອນ)

> **ສຳຄັນ:** ເທິງ iPhone/iPad ຂໍ້ມູນໃນ **Safari** ກັບໃນ **ແອັບທີ່ເພີ່ມໃສ່ໜ້າຈໍ** ແມ່ນແຍກກັນ.
> ໃຫ້ແມ່ຄ້າບັນທຶກຜ່ານໄອຄອນແອັບບ່ອນດຽວ. ຖ້າເຄີຍລອງໃນ Safari ແລ້ວຢາກຍ້າຍ → ສຳຮອງໃນ Safari → ກູ້ຄືນໃນແອັບ.

Android (Chrome): ⋮ → **Install app / ຕິດຕັ້ງແອັບ**.

## 6. ສຳຮອງ ແລະ ຍ້າຍຂໍ້ມູນ

- **ຕັ້ງຄ່າ → ດາວໂຫຼດໄຟລ໌ສຳຮອງ** (ຫຼື **ສົ່ງໄຟລ໌ສຳຮອງ** ໄປ LINE / WhatsApp / Google Drive / Files) → ໄດ້ໄຟລ໌ `dalin-stock-backup-YYYY-MM-DD.json`
- ເຄື່ອງໃໝ່: ເປີດແອັບ → **ຕັ້ງຄ່າ → ກູ້ຄືນຈາກໄຟລ໌** → ເລືອກໄຟລ໌ .json (ຂໍ້ມູນໃນເຄື່ອງນັ້ນຈະຖືກແທນທີ່)
- **CSV** (ລາຍການຂາຍ / ລັອດ / ຄ່າໃຊ້ຈ່າຍ) ໃຊ້ເປີດໃນ Excel / Google Sheets — ມີ BOM ໃຫ້ພາສາລາວສະແດງຖືກ. ການກູ້ຄືນໃຊ້ໄຟລ໌ JSON ເທົ່ານັ້ນ.
- ແອັບຈະເຕືອນ ຖ້າບໍ່ໄດ້ສຳຮອງເກີນ 7 ມື້.

ຂໍ້ມູນເກັບໃນ **IndexedDB** (ຮັບໄດ້ຫຼາຍປີຂອງການຂາຍ) ແລະ ສຳຮອງໃສ່ **LocalStorage** ອັດຕະໂນມັດ ຖ້າ IndexedDB ໃຊ້ບໍ່ໄດ້. ແອັບຂໍສິດ "ເກັບຖາວອນ" (`navigator.storage.persist()`) ເພື່ອບໍ່ໃຫ້ເຄື່ອງລຶບຂໍ້ມູນເອງ.

```
dalin-stock/

├─ index.html                     meta ສຳລັບ iPad (ເປີດເຕັມຈໍ)
├─ vite.config.js                 base: './' + PWA (manifest, service worker)
└─ src/
   ├─ main.jsx, App.jsx           ໂຄງໜ້າ, ແຖບເມນູລຸ່ມ, ແຖບແຈ້ງເຕືອນ
   ├─ index.css                   ສີ, ຟອນ (Noto Sans Lao Looped + Barlow ຕິດມາກັບແອັບ ໃຊ້ອອບລາຍໄດ້)
   ├─ pages/                      Dashboard, Sell, Lots, Expenses, Settings
   ├─ components/                 LotVisuals (ແຖບລັອດ + ທຸງຄືນທຶນ), Numpad, LotForm, LotDetail, Dialogs, ui
   └─ lib/
      ├─ calc.js (+ calc.test.js) ສູດຄິດໄລ່ທັງໝົດ
      ├─ store.js                 ຂໍ້ມູນ + ການບັນທຶກ
      ├─ storage.js               IndexedDB / LocalStorage
      ├─ backup.js                JSON / CSV
      ├─ demo.js                  ຂໍ້ມູນຕົວຢ່າງ
      ├─ units.js                 ໜ່ວຍຂາຍ, ສາເຫດຂອງເສຍ, ປະເພດຄ່າໃຊ້ຈ່າຍ
      ├─ format.js                ຮູບແບບເງິນ, ວັນທີພາສາລາວ
```

### ປັບແຕ່ງ

- **ຊື່ແອັບ** (ທີ່ສະແດງໃຕ້ໄອຄອນ): `APP_NAME`, `SHORT_NAME` ໃນ `vite.config.js` ແລະ `<title>` ໃນ `index.html`
- **ສີ**: ໃນ `@theme` ຂອງ `src/index.css`
- **ໜ່ວຍຂາຍ / ປຸ່ມຈຳນວນດ່ວນ / ປະເພດຄ່າໃຊ້ຈ່າຍ**: `src/lib/units.js`
- **ຂໍ້ມູນຕົວຢ່າງ**: `src/lib/demo.js`
